# Ciencia Mística

Primera versión estática de `valenfer.github.io/cienciamistica`: un archivo visual para explorar temas entre física teórica, filosofía, mística y literatura fronteriza.

## Ejecutar en local

Desde esta carpeta:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

Después abre `http://127.0.0.1:8765/`.

## Estructura

- `index.html`: interfaz, estilos, datos iniciales y navegación de artículos.
- `assets/`: ilustraciones SVG locales.
- `docs/superpowers/specs/`: especificación visual y funcional.
- `docs/superpowers/plans/`: plan de implementación.
- `FUENTES.md`: fuentes consultadas para la tarjeta sobre frecuencias Solfeggio.
